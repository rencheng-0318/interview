# Search experience

`app/search/page.tsx` is the starter shell. Build an intuitive search experience using the
provided API contract and server-side request helper.

Users must be able to submit a natural-language query, optionally filter by document type,
understand why each patient matched, and navigate to the existing patient-detail route.
Handle idle, loading, results, no-results, validation, and dependency-failure states.

The visual design, component structure, state management, and interaction details are
yours to choose. Keep credentials and server-only configuration out of browser code.
