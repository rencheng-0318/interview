# Candidate tests

The test harness and starter placeholders are provided. Replace the relevant `xfail`
placeholders with meaningful tests for your implementation.

Demonstrate the important behavior described in `docs/TAKE_HOME_DESIGN.md`, including
indexing safety, practice isolation, result behavior, request validation, and at least one
frontend state. Tests must be deterministic and must not require a paid or uncontrolled
external service.

The test boundaries, fixtures, setup, and assertions are yours to choose.
